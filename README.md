# QA_Sample_Website_Projects
QA Sample Projects containing manual testing artifacts for demo web applications, including Test Plans, Test Scenarios, Test Cases, Bug Reports, Traceability_Matrix , Test Execution Reports, and Test Summary Reports. Also includes Playwright automation and API testing examples.


## 📌 Project Overview

This project demonstrates a complete **Manual Software Testing process** for a web-based application.

The project follows a structured Software Testing Life Cycle (STLC) and includes requirement analysis, test planning, test scenario creation, test case design, test execution, defect reporting, traceability, and final test reporting.

The objective of this project is to ensure that the application meets its functional requirements, identify defects at an early stage, and verify the overall quality and reliability of the application.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Understand and analyze functional requirements
- Prepare a comprehensive Test Plan
- Design Test Scenarios
- Create detailed Test Cases
- Execute functional test cases
- Identify and report software defects
- Track defects through Bug Reports
- Maintain Requirement Traceability
- Prepare Test Execution Reports
- Prepare Test Summary Reports
- Evaluate the overall quality of the application
- Ensure that the application meets defined requirements
